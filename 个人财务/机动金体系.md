
> [!abstract] 一句话
> 不投资、不买理财。只盯银行里**可随时动用的现金**，攒到能让你「转身 / 逃逸 / 机动」的跑道长度。记账 app 管过程，你只管余额与目标线的差。

## 核心定义

- **机动金** = 银行活期 / 高流动性账户里、除去日常周转外的闲钱。
- **目的** = 三种场景的退出 / 选择能力，不是「资产增值」：
  - **逃逸**：不被财务绑架的退出能力（被裁、干不下去硬撑）
  - **转身**：职业 pivot 的过渡成本（离职准备、降薪期、去 AI Agent 岗位的空窗）
  - **机动**：地理 / 机会机动（换城押金、读研 / 出国保证金、抓突发机会的现金）

> [!important] 体系塌缩原则
> 既然不投资，本体系**没有收益维度**。所有复杂度都被记账 app 吸收，你只需维护一个量：**机动金余额 vs 目标线**。

## 目标线方程

```
机动金 Target = max( 逃逸线 , 转身线 , 机动线 )
```

| 场景 | 口径 | 公式（填空） |
|---|---|---|
| 逃逸线 | 不被绑架的硬撑月数 | `生存底线月支出__ × 安全月数__月` |
| 转身线 | 过渡 + 转型准备金 | `空窗__月 × 月支出 + 转型准备金__元` |
| 机动线 | 单笔最大机会成本 | **路径依赖极强，先定路径再定数**（见下） |

> 当前取三者的 **max**；也可分阶段（先达标逃逸线，再追转身 / 机动）。

### ⚠️ 机动线：先定留学路径，再定量级

机动线的量级**由路径决定，差一个数量级**，必须先把路径定下来：

- **路径 A · 自费硕士**（如美国藤校 / CS 强校 MS，多为自费）：量级 **百万级**。资金密集，对本体系是长极。
- **路径 B · 工作数年后申 PhD**（美国 CS PhD 多全奖：tuition waiver + stipend）：量级 **十万级**（申请费 + 语言/标化 + 过渡空窗 + 赴美搬迁）。
- **定路径 = 定目标数量级。** 路径 B 下当前余额通常已覆盖目标线，体系重心从「攒钱」转移到「规则 1：研究 / 技能资产化」。

> 若路径未定，机动线取两者中你心理上更可能的那个作为 binding Target；另一个记为「上限情景」。

## 四大规则（含元规则：防力工逻辑）

> [!warning] 元规则 · 防力工逻辑
> 力工逻辑 = 线性时间换钱 + 苦行省钱 + 靠意志力，从不复盘结构。本体系任何动作若滑向「多干 / 少花 / 靠忍」，立即触发复盘。

**规则 1 · 收入必须非线性化（最关键，也是唯一瓶颈）**
不靠加班时长。把 `agent-skill-infra` / `skill-router` / 论文视为**可计价资产**，从「爱好」变成「能卖钱 / 涨身价 / 能申请 PhD 的科研资产」。每月逼问：技能资产增值了吗？
> 当财务目标已被覆盖（路径 B），规则 1 从「加速攒钱」升级为「体系唯一约束」——它同时决定转身/逃逸/机动与 PhD 竞争力。

**规则 2 · 支出靠结构性决策，不靠苦行**
只做一次的大决策（住哪儿、通勤半径）压低固定成本，长期生效。日常消费不自律、不苦行——苦行是力工逻辑在省钱侧的翻版。

**规则 3 · 储蓄自动化**
发薪日自动 sweep 到独立账户。凡是需要「这个月我忍住不花」的，都是力工逻辑（靠意志力）。系统替你执行。

## 战略时间轴（按「干 X 年再申 PhD」规划）

- **财务目标**：路径 B 下，当前余额通常已覆盖目标线；储蓄率到顶后无优化空间，停止在「省钱」上内耗。
- **真正瓶颈 = 规则 1 的研究 / 技能资产**：PhD  admission 看科研履历（论文、强开源研究、牛推），与「转身/机动」要的底层能力是同一个东西。
- **X 年窗口的核心任务 = 长资产，不是攒钱**：把在职期当「科研资产积累期」，而非「线性时长换钱」。防力工逻辑在这里最致命——三年若只攒了存款没长资产，到期申请与反身机动性都会落空。
- **奖学金 / RA 是减压变量**：路径 B 中争取 RA / fellowship 可进一步降本，应作为计划的一部分而非侥幸。

## 消费治理（防力工逻辑在花钱侧的落地）

> [!info] 定位
> 储蓄率达标后，钱不再是约束；消费决策的质量，决定你是「在长资产」还是「在表演努力」。本节把「防力工逻辑」落到每一笔花钱上。

### 消费三分法
- **① 结构性固定成本**（对应规则 2）：租房、通勤半径等一次决策、长期生效，靠结构压低，不靠日常自律。
- **② 兴趣消费**：为快乐 / 放松服务，框架**明确允许**。苦行（为攒钱 denial 生活）本身就是力工逻辑；兴趣消费防 burnout，而 burnout 是资产建造的头号杀手。
- **③ 战术 / 生产力消费**：以「帮我工作」之名购买。最该过过滤器——它最容易伪装成资产投入。

### 消费决策过滤器（任何「要不要买」都过一遍）
```
1. 一次性资本消费，还是 recurring 固定成本？
2. 它服务 资产化(Rule1) 吗？有清晰链路才进下一关。  → 无链路 = 拒
3. 利用率够吗？（结合"在家时间有限"等现实算预期时长）  → 低利用 = 拒
4. 它是不是"环境优化式拖延"（力工逻辑变体：买装备 feel like 在优化工作流）？  → 是 = 拒
默认：不买。除非能过 2/3/4。
```

### 书的特例：拥有 ≠ 资产
- 读了且喂给研究 / 技能资产 → **资产化投入**（合法，甚至必需）
- 读了为快乐 → **兴趣消费**（合法）
- 没读，只是买 / 收藏 → **战术消费**（力工逻辑：买 = 勤奋的幻觉）
- 买前特化一问：「我会在 X 周内读完并作用到研究上吗？」答不出 = 拒。书自带 virtuous 光环，最会让人误以为在进步。

### 装备癖：力工逻辑在消费侧的那张脸
**成因**
- 进度错觉：买有清晰闭环（下单→拥有），真工作开放无终；大脑偷换成「买 = 进展」。
- 控制感代偿：真目标（申请 / 科研）不确定，选型号 / 比参数是你全控的确定域，用小事代偿大事焦虑。
- 身份消费：拥有 = 「我是认真的研究者」，免了成为研究者的挣扎。
- 准备陷阱：「等装备齐了再开始」，社会认可的正当拖延。

**如何污染其他决策**
- 模仿框架合法部分（Rule1 资产 / Rule3 系统），一旦开过「为生产力」的口子，合理化模式泛化，过滤器萎缩。
- 注意力挪用：装备要配置 / 学 / 调，元任务吃掉主任务。
- 决策预算错配：斟酌力花在比参数，而非选研究问题。
- 目标替换：可测的变成「装备齐了没」，研究进度被 proxy 掉。

**控制杠杆**
1. 冷却期：非必需超阈值消费，强制 48–72h，等 dopamine 退潮。
2. 反转举证责任：不问「该不该买」，问「这周哪件具体工作被它解锁？说不出就拒」。
3. 系统 vs 物件测试：它「不需我持续关注就自己跑」吗？系统被动、装备主动。
4. 装备硬上限：现有某件没充分利用前不买新的；或季度装备预算故意压小。
5. 进度指标外移：可视化追踪「资产进度」，装备冲动就失业（见月度复盘）。
6. 把「想买」当信号不是指令：urge 往往指向你正逃避的真工作。

### 体验型 vs 物件型：消费提升生活感知只对前者成立
- **体验型消费**（旅行 / 演出 / 课程 / 兴趣实践）确实持久提升生活感知——买的是「活过的时刻」。
- **物件 / 装备型消费**只提升「身份错觉」，不提升感知；许诺感知，兑现库存。
- 框架应为「在正确轴上消费」，不是「少消费」；过度苦行反伤资产化（感知麻木 / burnout）。
- **终极问**：这笔消费会抬高我的「活过的体验」，还是只抬高我的「拥有的清单」？体验 → 放行；库存 → 拒。

> 电子琴若真弹 = 体验 / 兴趣消费，放行；XR 当副屏 = 物件型、无资产链路，挡。
