# 技术人员周报邮件模板（华为责任结果导向 · 填空版）

> 用法：复制下方模板到邮件正文，把每一行的 `⟦ … ⟧` 替换成你的实际内容即可。
> 无需表格、无需复杂格式，直接粘贴进 Outlook / 邮箱就能用。
> 对应框架见 `技术人员周报写作指南.md`（双模板融合 + 责任结果贡献 + 轻量复盘）。

```
【一、本周关键结论】（领导先看这段）
- 我负责：⟦责任领域，如：订单域稳定性 / XX 模块交付⟧
- 结果：⟦一句话：本周结果如何⟧
- 关键数字：① ⟦数字+对比，如 P99 450→220ms⟧ ② ⟦数字+对比⟧ ③ ⟦数字+对比，含一项长期能力⟧
- 需领导决策：⟦事项 / 无⟧

【二、工作亮点（责任结果达成）】
1. 责任：我负责/主导 ⟦…⟧
   结果：完成 ⟦…⟧，状态 ⟦已提测/联调中/待上线⟧
   贡献：对⟦客户/同事/领导⟧ ⟦…⟧；长期沉淀 ⟦规范/流程/人才⟧
   数据：⟦量化对比，本周 vs 上周/目标⟧
（有多条就复制 1. 的格式继续写）

【三、工作暗点 / 风险（主动暴露）】
- 问题：⟦…⟧ → 根因：⟦…⟧ → 影响的责任结果：⟦…⟧ → 已动作：⟦…⟧ → 需支持：⟦…⟧
（有多条继续写）

【四、下一步行动（可验收）】
- P0：目标 ⟦…⟧ / 动作 ⟦…⟧ / 成功标准 ⟦…⟧
- P1：目标 ⟦…⟧

【五、需要的支持 & 资源到位后我能帮到谁】
- 当前缺口（要资源）：⟦…⟧
- 假如资源到位：帮客户 ⟦…⟧、帮同事 ⟦…⟧、帮领导 ⟦…⟧

【六、用数据表态】（如涉及表扬/批评）
- ⟦纯数据，不情绪化⟧

【轻量复盘】（重大成败时写；平时可省略）
- ⟦复盘·亮点/暗点⟧：意图 ⟦…⟧；发生 ⟦…⟧；学到 ⟦…⟧；已做 ⟦…⟧；已分享 ⟦…⟧
```

## 填写示例（已填好，供对照形状）

【一、本周关键结论】
- 我负责：订单域稳定性与优惠券交付
- 结果：核心接口性能达标，优惠券核销进入联调
- 关键数字：① P99 延迟 450→220ms（-51%）② 线上缺陷 5→3（-40%）③ 沉淀《高并发幂等规范》1 份
- 需领导决策：无

【二、工作亮点（责任结果达成）】
1. 责任：我主导订单高并发重复提交修复
   结果：完成幂等校验+3 条单测，已联调
   贡献：对客户减少超卖客诉；长期沉淀《幂等规范》
   数据：重复提交归零，联调耗时 -1 天
2. 责任：我负责优惠券核销接口开发
   结果：接口开发完成，联调中
   贡献：对业务支撑大促发券；长期沉淀接口契约
   数据：测试覆盖率 85%

【三、工作暗点 / 风险】
- 问题：测试环境 DB 频繁超时 → 根因：疑似资源不足 → 影响：集成进度约 4h → 已动作：重启无效 → 需支持：申请运维深度诊断

【四、下一步行动】
- P0：优惠券核销上线 / 动作：完成回归+灰度 / 成功标准：无 P0 缺陷上线
- P1：推动《幂等规范》团队评审

【五、需要的支持 & 资源到位后我能帮到谁】
- 当前缺口：测试资源紧张
- 假如资源到位：帮客户把验收周期 5→3 天；帮同事分担回归；帮领导提前 2 天释放交付风险

【六、用数据表态】
- 本周质量贡献：缺陷 -40%、告警 -35%

【轻量复盘】
- 复盘·暗点：订单超卖事故：意图零资损；发生因幂等缺失 3 笔重复；学到并发校验需全覆盖；已做补幂等+沉淀规范；已分享给 2 个兄弟模块
