# 机动金体系

> [!abstract] 一句话
> 不投资、不买理财。只盯银行里**可随时动用的现金**，攒到能让你「转身 / 逃逸 / 机动」的跑道长度。记账 app 管过程，你只管余额与目标线的差。

## 核心定义

- **机动金** = 银行活期 / 高流动性账户里、除去日常周转外的闲钱。
- **目的** = 三种场景的退出 / 选择能力，不是「资产增值」：
  - **逃逸**：不被财务绑架的退出能力（被裁、干不下去硬撑）
  - **转身**：职业 pivot 的过渡成本（离职准备、降薪期、去 AI Agent 岗位的空窗）
  - **机动**：地理 / 机会机动（换城押金、读研 / 出国保证金、抓突发机会的现金）

> [!important] 体系塌缩原则
> 既然不投资，本体系**没有收益维度**。所有复杂度都被记账 app 吸收，你只需维护一个量：**机动金余额 vs 目标线**。

## 目标线方程

```
机动金 Target = max( 逃逸线 , 转身线 , 机动线 )
```

| 场景 | 口径 | 公式（填空） |
|---|---|---|
| 逃逸线 | 不被绑架的硬撑月数 | `生存底线月支出__ × 安全月数__月` |
| 转身线 | 过渡 + 转型准备金 | `空窗__月 × 月支出 + 转型准备金__元` |
| 机动线 | 单笔最大机会成本 | **路径依赖极强，先定路径再定数**（见下） |

> 当前取三者的 **max**；也可分阶段（先达标逃逸线，再追转身 / 机动）。

### ⚠️ 机动线：先定留学路径，再定量级

机动线的量级**由路径决定，差一个数量级**，必须先把路径定下来：

- **路径 A · 自费硕士**（如美国藤校 / CS 强校 MS，多为自费）：量级 **百万级**。资金密集，对本体系是长极。
- **路径 B · 工作数年后申 PhD**（美国 CS PhD 多全奖：tuition waiver + stipend）：量级 **十万级**（申请费 + 语言/标化 + 过渡空窗 + 赴美搬迁）。
- **定路径 = 定目标数量级。** 路径 B 下当前余额通常已覆盖目标线，体系重心从「攒钱」转移到「规则 1：研究 / 技能资产化」。

> 若路径未定，机动线取两者中你心理上更可能的那个作为 binding Target；另一个记为「上限情景」。

## 三数追踪（每月更新一次）

| 指标 | 含义 | 当前值 |
|---|---|---|
| 当前余额 | 银行机动金实际数 | `__ 元` |
| 月储蓄率 | (收入 − 支出) / 收入 —— 早期唯一重要指标 | `__ %` |
| 预计达成月 | (Target − 当前) / 月储蓄额 | `__ 月` |

> 若已覆盖目标线（如路径 B），「预计达成月」失去意义，改为追踪「资产进度」（见战略时间轴）。

## 四大规则（含元规则：防力工逻辑）

> [!warning] 元规则 · 防力工逻辑
> 力工逻辑 = 线性时间换钱 + 苦行省钱 + 靠意志力，从不复盘结构。本体系任何动作若滑向「多干 / 少花 / 靠忍」，立即触发复盘。

**规则 1 · 收入必须非线性化（最关键，也是唯一瓶颈）**
不靠加班时长。把 `agent-skill-infra` / `skill-router` / 论文视为**可计价资产**，从「爱好」变成「能卖钱 / 涨身价 / 能申请 PhD 的科研资产」。每月逼问：技能资产增值了吗？
> 当财务目标已被覆盖（路径 B），规则 1 从「加速攒钱」升级为「体系唯一约束」——它同时决定转身/逃逸/机动与 PhD 竞争力。

**规则 2 · 支出靠结构性决策，不靠苦行**
只做一次的大决策（住哪儿、通勤半径）压低固定成本，长期生效。日常消费不自律、不苦行——苦行是力工逻辑在省钱侧的翻版。

**规则 3 · 储蓄自动化**
发薪日自动 sweep 到独立账户。凡是需要「这个月我忍住不花」的，都是力工逻辑（靠意志力）。系统替你执行。

## 里程碑：三道门槛

```
3月 runway  → 不再怕突然失业（基础安全感）
6月 runway  → 敢拒绝恶心的事（"逃逸"解锁）
12月 runway → 敢裸辞 pivot / 抓机会（"转身+机动"解锁）
```
> 若路径 B 已覆盖目标线，这三道门槛视为「已解锁」，重心转到资产里程碑。

## 战略时间轴（按「干 X 年再申 PhD」规划）

- **财务目标**：路径 B 下，当前余额通常已覆盖目标线；储蓄率到顶后无优化空间，停止在「省钱」上内耗。
- **真正瓶颈 = 规则 1 的研究 / 技能资产**：PhD  admission 看科研履历（论文、强开源研究、牛推），与「转身/机动」要的底层能力是同一个东西。
- **X 年窗口的核心任务 = 长资产，不是攒钱**：把在职期当「科研资产积累期」，而非「线性时长换钱」。防力工逻辑在这里最致命——三年若只攒了存款没长资产，到期申请与反身机动性都会落空。
- **奖学金 / RA 是减压变量**：路径 B 中争取 RA / fellowship 可进一步降本，应作为计划的一部分而非侥幸。
